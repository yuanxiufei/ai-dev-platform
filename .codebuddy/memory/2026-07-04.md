## 桌面端保存文件闪退修复 + 全面增强

### 根因分析
1. **文件监听器回环** — 保存文件后 file_watcher 立即检测到 Modify 事件并发射给前端，可能导致状态冲突
2. **tauri-plugin-fs 命令冲突** — 插件注册的 fs 命令与自定义 commands/fs 同名，潜在冲突
3. **Rust warnings (11个)** — 未使用的函数/结构体，`parking_lot::Mutex::lock()` 不返回 Result 的编译错误
4. **前端无保存保护** — 并发保存可能造成竞态条件
5. **`panic = "abort"`** — release 模式下任意 panic 直接杀进程，无恢复机会

### 修复内容

#### Rust 后端 (8 文件修改)
- **file_watcher.rs**: 新增 `WatcherState` 结构，记录最近保存文件的路径（500ms debounce），`notify_saved()` 通知抑制自触发事件；修 `lock()` 不返回 Result 的编译错误
- **commands/fs.rs**: `write_file` 增加空路径校验、parent 更有意义的检测、调用 `file_watcher::notify_saved()` 通知
- **main.rs**: `setup_panic_hook()` 崩溃写入 `%APPDATA%/codebuddy-crash.log`；调用 `git::init/terminal::init/settings::init` 解决 unused 警告；禁用 `tauri_plugin_fs::init()`
- **git.rs, terminal.rs, plugins.rs, shortcuts.rs**: 添加 `#[allow(dead_code)]` 消除警告
- **commands/git.rs**: `///` → `//` (doc comment on statement)
- **commands/search.rs**: 移除 `mut`
- **commands/plugins.rs**: `plugin` → `_plugin`
- **tauri.conf.json**: 移除 `plugins.fs` 配置

#### 前端增强
- **useEditorStore.ts**: 
  - `saveActiveFile`/`saveAllFiles` 增加 `_isSaving` 防重入保护 + 200ms 节流
  - 保存前 snapshot path/content，保存后仅更新当前标签页
  - 新增 **auto-save** 功能（1s 延迟，可开关）
  - 新增 **window title sync**（watch 文件路径 + modified 状态 → `document.title`）
- **useKeybindingStore.ts** (之前修复): 输入控件内普通字符键放行
