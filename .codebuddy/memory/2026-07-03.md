## Terminal input 问题根因分析 (对比 VSCode)
- **核心差异**: VSCode 用 xterm.js + Canvas 渲染，**无任何可见 HTML input**；键盘输入通过隐藏 `<textarea>` (opacity:0, left:-9999em) 捕获后在 Canvas 上渲染
- **当前问题**: 我们用的是可见的 HTML `<input type="text">`，怎么隐藏样式都会有"网页输入框感"
- **xterm.js DOM 结构**: `.xterm > .xterm-screen > canvas`（渲染层）+ `.xterm > .xterm-helpers > .xterm-helper-textarea`（隐藏输入层）
- **VSCode Tab 布局**: SplitView 水平分割（Tab栏 | 终端内容），Tab栏基于自定义 List 组件，工具栏用 ActionBar
- **两个方案**: ①引入 xterm.js 做真终端 ②保持当前架构但模仿 xterm 隐藏 textarea + 渲染到输出区
